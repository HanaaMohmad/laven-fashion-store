# LAVEN — متجر ملابس متجاوب

## التشغيل
افتح `index.html` في المتصفح. يحتاج اتصالًا بالإنترنت لعرض صور Unsplash وخط Google Fonts.

## الملفات
- `index.html`: هيكل المتجر والأقسام.
- `style.css`: التصميم المتجاوب، الوضع الليلي والحركات.
- `script.js`: عرض المنتجات والفلترة والبحث والمفضلة وسلة المشتريات.

## قبل النشر كمتجر تجاري فعلي
- صور المنتجات وروابط الشبكات الاجتماعية والبريد الحالي أمثلة قابلة للاستبدال.
- الأسعار والمنتجات تجريبية.
- السلة تعمل داخل المتصفح، لكن تأكيد الطلب لا يرسل طلبًا إلى خادم أو بوابة دفع. يلزم ربطه بخدمة خلفية أو WhatsApp/نظام متجر قبل استقبال طلبات حقيقية.
